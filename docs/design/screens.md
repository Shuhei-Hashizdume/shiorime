# SHIORIME 画面設計

この文書は、画面ごとの配置・ボタン・移動先・文言・状態をまとめたものです。見た目（色・書体・動き）は [visual.md](visual.md)、何を作るかは [../requirements.md](../requirements.md) に従います。見本は [mockups/](mockups/) を参照してください。

## 目次

1. [本棚（トップ）](#1-本棚トップ)
2. [本の検索・登録](#2-本の検索登録)

各画面には「表示する項目と、その項目がどこから来るか」の表を置く。理由：データのない項目を画面に載せてしまうのを防ぎ、api.md・database.md を作るときの確認表にするため。

## 1. 本棚（トップ）

見本：[mockups/shelf.html](mockups/shelf.html)

### 配置（上から順に）

| 部品 | 内容 |
| --- | --- |
| 見出し | 「本棚」。右側に、選んでいる切り替えの冊数（例：「7冊」） |
| 切り替え | 「読書中」「読了」「すべて」の順。初めは「読書中」を選んだ状態 |
| 本の一覧 | 表紙を3列で並べる。表紙の下にタイトル（2行まで、それ以上は「…」で省略）と読書ステータス（「読書中」または「✓読了」） |
| 本を追加 | 右下に「＋本を追加」のボタン。共通メニューの上に置く |
| 共通メニュー | 本棚（選択中）・気づき・プロフィール |

- 冊数は、選んでいる切り替えの冊数を表示する。理由：見出しの冊数と並んでいる冊数がずれると、混乱するため。
- 切り替えの順番を「読書中・読了・すべて」とし、初めは「読書中」にする。理由：利用者は、今読んでいる本に気づきを書くことが最も多いため。
- 切り替えの選択中は、枠線と薄い灯りの色で表す（visual.md「3. 色」のとおり）。塗りつぶしは「本を追加」だけにする。
- 表紙がない本・手入力の本は、アプリのアイコン画像で表示する（要件定義書 5.2 のとおり）。
- 一覧の最後の行が「本を追加」に隠れないよう、一覧の下にボタンの高さ分の余白をあける。

### 表示する項目と出どころ

| 項目 | 出どころ |
| --- | --- |
| 表紙 | データベース（本の表紙の URL）。ない場合はアイコン画像 |
| タイトル | データベース |
| 読書ステータス | データベース |
| 冊数 | データベース（選んでいる切り替えの条件で数える） |

### 並び順と読み込み

- 並び順：登録した日時が新しい順（固定）。理由：利用者が予想しやすいため。並び順を選べる機能は MVP では作らない。
- 30冊ずつ読み込み、一覧の下までスクロールしたら次の30冊を自動で読み込む。理由：本が数百冊になっても、最初の表示が遅くならないようにするため。
- 次の30冊の読み込みに失敗した場合は、一覧の下に「読み込めませんでした」と「もう一度読み込む」ボタンを表示する。

### 操作と移動先

| 操作 | 結果 |
| --- | --- |
| 表紙またはタイトルを押す | 本の詳細へ |
| 切り替えを押す | その読書ステータスの本だけを表示（「すべて」は全部） |
| 「＋本を追加」を押す | 本の検索・登録へ |
| 共通メニュー | 各画面へ |

- 本の編集・削除は本棚では行わず、本の詳細の「⋮」メニューから行う。理由：表紙を並べた画面には操作を置く場所がなく、誤って削除するのも防げるため。
- 選んだ切り替えは URL に入れる（例：`/shelf?status=finished`）。
  - 本の詳細から戻るボタンで戻ったときは、選んでいた切り替えのまま戻る。
  - アプリを開き直したときと、共通メニューの「本棚」を押したときは「読書中」から始まる。
  - 理由：ブラウザの戻る操作で自然に元の状態に戻せ、状態を保存する仕組みを別に作らずに済むため。

### 状態

| 状態 | 表示 |
| --- | --- |
| 読み込み中 | 表紙と同じ形のスケルトン（3列×3行） |
| 通常 | 本の一覧 |
| 本がまだない | アイコン、「最初の1冊を、本棚に。」、「いま読んでいる本や、気になっている本を追加しましょう。」、「本を追加する」ボタン。切り替えと右下のボタンは出さない |
| 選んだ切り替えの本がない（本はある） | 「読書中の本はありません」（読了・すべての場合はそれぞれの名前）、「読み終えた本は「読了」で見られます。」（読書中のときだけ）、「本を追加する」ボタン。右下のボタンは出さない |
| 読み込みの失敗 | 「本棚を読み込めませんでした。時間をおいてもう一度お試しください。」と「もう一度読み込む」ボタン |

- 「本がまだない」と「選んだ切り替えの本がない」は、別の表示にする。理由：本が1冊もない人には登録を勧め、読書中の本がないだけの人には、本がどこにあるかを伝えるため。

### 関連する決まり（ほかの画面に関わるもの）

- 本を「読了」に変えたときのトーストは「読了にしました（本棚の「読了」に移りました）」とする。理由：本棚を「読書中」から開くため、読了にした本が見えなくなり、消えたと思われるのを防ぐため。
- 登録時に「読了」を選んだ本も、登録後は本の詳細に移るため、同じ理由で、本の詳細に読書ステータスを表示しておく。

### API（api.md で詳しく決める）

- 本の一覧の取得：読書ステータスでの絞り込み（読書中／読了／指定なし）と、30冊ずつの読み込み（続きの位置を渡す方式）に対応する。
- 冊数は、絞り込みの条件ごとに返す。
- 自分の本だけを返す。ほかの利用者の本は、条件を変えても返さない（全画面の API で共通の決まり）。

## 2. 本の検索・登録

見本：[mockups/search.html](mockups/search.html)

本棚の「本を追加」から開く。Google Books で検索して選ぶか、見つからない場合は手入力で追加する。

### 配置（上から順に）

| 部品 | 内容 |
| --- | --- |
| 見出し | 左に戻るボタン、「本を追加」 |
| 検索欄 | 「タイトル・著者名で検索」。入力があるときは右に消すボタン。画面を開くと自動でカーソルが入る |
| 検索結果 | 1行に1冊。表紙・タイトル・著者・出版年。本棚にある本には「✓本棚にあります」 |
| 手入力の案内 | 「手入力で追加する」と、その下に「※検索で見つからない本は、タイトルと著者を入力して追加できます。」 |
| 共通メニュー | 本棚（選択中）・気づき・プロフィール |

- 手入力の案内は、検索前・検索結果の一番下・見つからないときの3か所に置く。理由：手入力がどういうときに使うものかを、初めての人にもわかるようにするため。
- 「本棚にあります」は、枠線と薄い灯りの色で表す（押すボタンと見分けるため。visual.md「3. 色」のとおり）。

### 表示する項目と出どころ

| 項目 | 出どころ |
| --- | --- |
| 表紙 | Google Books（サーバーで https に直して渡す）。ない場合はアイコン画像 |
| タイトル | Google Books |
| 著者 | Google Books（複数いる場合は「、」でつなぐ）。ない場合は表示しない |
| 出版年 | Google Books の出版日の年の部分。ない場合は表示しない。**表示するだけで、本棚に追加するときは保存しない** |
| 本棚にあるか | サーバーで、Google Books の識別子と自分の本棚の本を照らし合わせて判定する |

- 出版年を保存しない理由：役に立つのは、同じ本の複数の版から1つを選ぶ検索のときだけであり、データベースと要件（本の情報はタイトル・著者・ISBN・表紙）を変えずに済むため。保存が必要になれば後から追加できる。

### 検索

- キーボードの「検索」か Enter を押したときだけ検索する。入力のたびには検索しない。理由：日本語は変換の途中でも文字が変わり、無駄な検索が増えるため。Google Books の利用回数の上限を守るため。
- 前後の空白を除いて空の場合は、検索しない。
- 画面から Google Books を直接呼ばず、自分のサーバーを通す。理由：API キーを画面側のコードに置かないため。表紙の URL を https に直す処理と、検索の回数制限をサーバーの1か所にまとめるため。
- 検索の回数制限：1人あたり1分に10回まで。理由：普通に使えば届かない回数にし、自動で大量に検索されて Google Books の利用枠を使い切られるのを防ぐため。
- 結果は20件ずつ表示し、一番下に「もっと見る」ボタンを置く。理由：目当ての本は上のほうにあることがほとんどで、自動で読み込み続けると無駄な検索が増えるため。

### 操作と移動先

| 操作 | 結果 |
| --- | --- |
| 戻るボタン | 本棚へ（本棚で選んでいた切り替えのまま） |
| 検索結果の本を押す | 「本棚に追加」のシートを開く |
| 「本棚にあります」の本を押す | その本の詳細へ |
| 「手入力で追加する」 | 「手入力で追加」のシートを開く |
| シートの「本棚に追加する」 | 本を追加して本の詳細へ移り、トースト「本棚に追加しました」 |
| シートの「キャンセル」・シートの外を押す・下にスワイプ・Esc キー | シートを閉じる（何も追加しない） |

### シート

**本棚に追加（検索結果から）**
- 選んだ本の表紙・タイトル・著者・出版年
- 読書ステータス：「読書中」「読了」（初めは「読書中」）
- 「本棚に追加する」「キャンセル」
- 理由：押し間違えてもすぐには追加されず、版の確認と読書ステータスの選択を1か所でできるため。

**手入力で追加**
- タイトル（必須）：検索した言葉を最初から入れておく
- 著者（任意）
- 読書ステータス：「読書中」「読了」（初めは「読書中」）
- 「本棚に追加する」「キャンセル」
- 表紙はアプリのアイコン画像を使う（要件定義書 5.2 のとおり）。
- タイトルが空のまま「本棚に追加する」を押した場合は、タイトル欄の下に「タイトルを入力してください」と表示する。
- タイトル・著者の文字数の上限は、database.md で決める。

### 状態

| 状態 | 表示 |
| --- | --- |
| 開いたとき（検索前） | 「本のタイトルや著者名を入れて、キーボードの「検索」を押してください。」と手入力の案内 |
| 検索中 | 結果と同じ形のスケルトン |
| 検索結果 | 結果の一覧、一番下に「もっと見る」（続きがある場合）と手入力の案内 |
| 見つからない | 「見つかりませんでした」「言葉を短くしたり、著者名で探したりすると見つかることがあります。」、「手入力で追加する」ボタンと説明 |
| 検索の失敗（Google Books の障害など） | 「本を検索できませんでした。時間をおいてもう一度お試しください。」と手入力の案内 |
| 検索の回数制限に達した | 「検索の回数が多すぎます。1分ほど待ってから、もう一度お試しください。」 |
| 追加の失敗 | シートの中に「本棚に追加できませんでした。もう一度お試しください。」（シートは閉じない） |
| 追加しようとした本が既に本棚にある | シートを閉じて、その本の詳細へ移り、「この本は既に本棚にあります」と表示する（要件定義書 5.2 のとおり。別の端末から追加していた場合などに起きる） |

### API（api.md で詳しく決める）

- 本の検索：検索の言葉と、何件目からかを受け取り、20件と「続きがあるか」を返す。各結果に「本棚にあるか」と、本棚にある場合はその本の ID を含める。回数制限：1人1分10回。
- 本の追加（検索結果から）：Google Books の識別子と読書ステータスを受け取る。タイトル・著者・表紙・ISBN は、改ざんを防ぐため、サーバーが Google Books から取り直して保存する。
- 本の追加（手入力）：タイトル・著者・読書ステータスを受け取る。

## 3. 本の詳細

見本：[mockups/book.html](mockups/book.html)

本棚にある1冊の本の画面。読書ステータスの変更、気づきを書く・見る、本の編集・削除を行う。本棚から削除した本の詳細は開けない（削除した本の気づきは、気づき一覧から見る）。

### 入り口

| どこから | どうすると |
| --- | --- |
| 本棚 | 表紙かタイトルを押す |
| 本の検索（まだ本棚にない本） | 確認シートの「本棚に追加する」を押す |
| 本の検索（すでに本棚にある本） | 結果の本を押す（確認シートは出ない） |
| 手入力で追加 | シートの「本棚に追加する」を押す |

- 確認シートの表紙・タイトルは、押しても何も起きない。理由：本の詳細は本棚にある本の画面であり、まだ追加していない本には詳細の画面がないため。

### 配置（上から順に）

| 部品 | 内容 |
| --- | --- |
| 見出し | 左に戻るボタン、右に「⋮」 |
| 本の情報 | 表紙・タイトル・著者（著者がない本は、著者の行を出さない） |
| 読書ステータス | 「読書中」「✓読了」の切り替え。押すとすぐ保存する |
| この本の気づき | 件数と「この本の気づきを見る ＞」。0件のときは「心に残った一文や、読んで考えたことを書き留めてみましょう。」 |
| 気づきを書く | 「＋気づきを書く」（灯りの色で塗りつぶす） |
| 共通メニュー | 本棚（選択中）・気づき・プロフィール |

- 本の気づきを並べて表示するのは「本ごとの気づき一覧」だけとし、この画面には件数と移動のボタンだけを置く（要件定義書 5.4 のとおり）。
- ISBN と登録日は表示しない。理由：利用者が見ても役に立たないため。

### 表示する項目と出どころ

| 項目 | 出どころ |
| --- | --- |
| 表紙・タイトル・著者 | データベース（本） |
| 読書ステータス | データベース（本） |
| 気づきの件数 | データベース（この本の気づきを数える） |
| 編集できるか | データベース（Google Books の識別子がない本＝手入力の本だけ編集できる） |

### 操作と移動先

| 操作 | 結果 |
| --- | --- |
| 戻るボタン | 前の画面へ。ただし本を追加した直後は本棚へ（下の補足） |
| 読書ステータスを押す | すぐ保存し、トーストを出す（下の表） |
| 「この本の気づきを見る」 | 本ごとの気づき一覧へ |
| 「＋気づきを書く」 | 気づきの作成へ（本は選択済み） |
| 「⋮」 | メニューのシートを開く |

- 本を追加した直後の戻るボタン：検索画面ではなく本棚に戻る。実装では、追加後に本の詳細へ移るとき、ブラウザの履歴の検索画面を本の詳細で置き換える。理由：追加し終えたあとに検索結果へ戻っても、することがないため。

### 読書ステータスの変更

| 変更 | トースト |
| --- | --- |
| 読書中 → 読了 | 「読了にしました（本棚の「読了」に移りました）」 |
| 読了 → 読書中 | 「読書中にしました」 |

- 確認は出さない。理由：すぐ元に戻せる操作のため。
- 保存に失敗した場合は、切り替えを元に戻し、「読書ステータスを変更できませんでした。もう一度お試しください。」と表示する。理由：画面の表示と保存されている内容がずれないようにするため。

### 「⋮」メニュー

| 本の種類 | メニュー |
| --- | --- |
| Google Books から追加した本 | 「本棚から削除」だけ |
| 手入力で追加した本 | 「本の情報を編集」「本棚から削除」 |

- 「本棚から削除」は夕焼けの色にする。メニューの一番下に「キャンセル」。
- Google Books から追加した本は編集できない（要件定義書 5.2 のとおり）。画面で出さないだけでなく、サーバーでも受け付けない。

### シート

**本の情報を編集（手入力の本だけ）**
- タイトル（必須）・著者（任意）。今の値を最初から入れておく。
- 「保存する」「キャンセル」。保存したらトースト「本の情報を変更しました」。
- タイトルが空の場合は、タイトル欄の下に「タイトルを入力してください」。
- 保存に失敗した場合は、シートの中に「保存できませんでした。もう一度お試しください。」（シートは閉じない）。

**削除の確認**
- 「この本を本棚から削除しますか？」「この本の気づきは、気づき一覧に残ります。」（要件定義書 5.2 のとおり）
- 「削除する」（夕焼けの色）「キャンセル」。
- 削除したら本棚へ戻り、トースト「本棚から削除しました」。

### 状態

| 状態 | 表示 |
| --- | --- |
| 読み込み中 | 表紙・タイトル・切り替えの形のスケルトン |
| 通常 | 上の配置のとおり |
| 追加した直後 | 通常の表示に、トースト「本棚に追加しました」。トーストを出している間は、その分だけ画面の下に余白をとり、「＋気づきを書く」が隠れないようにする |
| 既に本棚にある本を追加しようとした | 画面の上に「この本は既に本棚にあります」（枠線と薄い灯りの色）。トーストは成功の知らせだけに使う決まりのため使わない |
| 本が見つからない（削除済み・他人の本・存在しない ID） | 「この本は見つかりませんでした」と「本棚へ戻る」ボタン。他人の本も同じ表示にする（他人の本があるかどうかを知らせないため） |
| 読み込みの失敗 | 「本を読み込めませんでした。時間をおいてもう一度お試しください。」と「もう一度読み込む」ボタン |

### API（api.md で詳しく決める）

- 本の取得：本の情報・読書ステータス・気づきの件数・編集できるかを返す。自分の本でなければ「見つからない」として返す。
- 読書ステータスの変更、本の情報の編集（手入力の本だけ。Google Books の本は拒否する）、本の削除。

## 4. 気づき一覧

見本：[mockups/notes.html](mockups/notes.html)

共通メニューの「気づき」から開く。本棚にある本を、気づきが0件の本も含めて1つの一覧で並べる。どの本を押しても「本ごとの気づき一覧」に移り、そこから気づきを書ける（要件定義書 5.4 のとおり）。

### 配置（上から順に）

| 部品 | 内容 |
| --- | --- |
| 見出し | 「気づき一覧」。右に気づきの総数（例：「気づき 16件」） |
| 並び順 | 左に「並び順：最近書いた順」、右に並び替えのアイコン（上下の矢印。文字は付けない） |
| 本の一覧 | 1冊ずつカード。表紙・タイトル・「気づき ◯件」・「最後に書いた日：10月20日」（今日は「今日」。0件の本は出さない）。削除済みの本には「本棚から削除済み」 |
| 共通メニュー | 本棚・気づき（選択中）・プロフィール |

- 見出しを「気づき」ではなく「気づき一覧」にする。理由：本ごとの一覧や気づきの詳細ではなく、全体の一覧であることがわかるようにするため。共通メニューの文字は、幅が限られるため「気づき」のままとする。
- 見出しの右には冊数を出さない。理由：本棚の冊数と同じ数字になり、意味が重なるため。
- 段（気づきのある本／ない本）には分けない。0件の本を探すときは、並び替えの「気づきが少ない順」を使う。
- 削除済みの本は、表紙を少し薄くし、灰色の枠で「本棚から削除済み」と表示する。灯りの色は使わない（注意を引く必要がないため）。
- この画面には「気づきを書く」ボタンを置かない。理由：気づきは必ず本を選んで書くため。本を押した先の画面から書く。

### 表示する項目と出どころ

| 項目 | 出どころ |
| --- | --- |
| 表紙・タイトル | 本棚にある本はデータベース（本）。削除済みの本は、気づきに記録した本の情報（要件定義書 5.3 のとおり） |
| 気づきの件数 | データベース（本ごとに数える） |
| 最後に書いた日 | データベース（本ごとに、気づきの作成日時の最も新しいもの） |
| 本棚から削除済みか | データベース |
| 気づきの総数 | データベース（自分の気づきを数える） |

### 並び替え

| 並び順 | 並べ方 | 同じ件数・0件どうしのとき |
| --- | --- | --- |
| 最近書いた順（初め） | 最後に気づきを書いた日時が新しい本から。0件の本は最後 | 本棚に登録した日時が新しい本から |
| 気づきが多い順 | 気づきの件数が多い本から | 最後に書いた日時が新しい本から |
| 気づきが少ない順 | 気づきの件数が少ない本（0件）から | 本棚に登録した日時が新しい本から |

- 並び替えのアイコンは、文字を付けずアイコンだけにする。理由：上下の矢印で意味が伝わり、左に今の並び順を表示しているため。押せる範囲は44px四方とし、画面読み上げ用に「並び替え」という名前を付ける（aria-label）。
- 並び替えのアイコンを押すと、下からシートを開く。3つの並び順と、それぞれの説明（例：「まだ気づきのない本から」）を並べ、今の並び順に印を付ける。選ぶとシートを閉じ、すぐ並び替える。「キャンセル」で何も変えずに閉じる。
- 並び替えはサーバー（データベース）で行う。理由：30冊ずつ読み込むため、画面側で並び替えると、まだ読み込んでいない本が順番に入らないため。
- 選んだ並び順は URL に入れる（例：`/notes?sort=few`）。本ごとの気づき一覧から戻ったときは同じ並び順のまま戻り、共通メニューから開き直したときは「最近書いた順」に戻る（本棚の切り替えと同じ考え方）。
- 読み込みは30冊ずつ、下までスクロールしたら次を読み込む（本棚と同じ）。

### 操作と移動先

| 操作 | 結果 |
| --- | --- |
| 本を押す（0件の本も含む） | その本の「本ごとの気づき一覧」へ |
| 並び替えのアイコン | 並び替えのシートを開く |
| 共通メニュー | 各画面へ |

- 0件の本を押した場合も、気づきの作成に直接は移らず「本ごとの気づき一覧」へ移る。移った先には「まだ気づきがありません」と「＋気づきを書く」を出す。理由：どの本を押しても行き先が同じ方が迷わないため。気づきタブ → 本 → 気づきを書く、の3回で書け、本棚から書く場合と同じ回数になる。

### 状態

| 状態 | 表示 |
| --- | --- |
| 読み込み中 | カードと同じ形のスケルトン |
| 通常 | 本の一覧 |
| 本はあるが、気づきがまだない | すべての本が「気づき 0件」で並ぶ（特別な表示はしない） |
| 本棚に本が1冊もなく、削除済みの本の気づきもない | アイコン、「まだ本がありません」、「本棚に本を追加すると、ここから気づきを書けるようになります。」、「本を追加する」ボタン（本の検索・登録へ） |
| 読み込みの失敗 | 「気づき一覧を読み込めませんでした。時間をおいてもう一度お試しください。」と「もう一度読み込む」ボタン |

### API（api.md で詳しく決める）

- 気づき一覧の取得：並び順（最近書いた順・多い順・少ない順）と、30冊ずつの読み込みに対応する。本ごとに、表紙・タイトル・気づきの件数・最後に書いた日時・削除済みかを返す。気づきの総数も返す。
- 本棚にある本と、削除済みの本（気づきに記録した本の情報でまとめる）を1つの一覧として返す。自分のものだけを返す。

## 5. 本ごとの気づき一覧

見本：[mockups/booknotes.html](mockups/booknotes.html)

1冊の本の気づきを並べる画面。気づきを押すと「気づきの詳細」に移る。

### 入り口

| どこから | どうすると |
| --- | --- |
| 気づき一覧 | 本を押す（0件の本も含む） |
| 本の詳細 | 「この本の気づきを見る」を押す |

### 配置（上から順に）

| 部品 | 内容 |
| --- | --- |
| 見出し | 左に戻るボタン |
| 本の情報 | 表紙・タイトル・著者・「気づき ◯件」。削除済みの本は「本棚から削除済み」 |
| 気づきの一覧 | 1件ずつカード（下の表） |
| 気づきを書く | 右下に「＋気づきを書く」（本棚の「本を追加」と同じ形） |
| 共通メニュー | 本棚・気づき（選択中）・プロフィール |

**気づきのカード**

| 項目 | 表示 |
| --- | --- |
| ページ | 「P.142」。ないときは「ページなし」 |
| 書いた日 | 「10月18日」（今日は「今日」） |
| 引用 | 紙片で表す（visual.md「6. 栞と引用の表現」のとおり）。2行まで、はみ出す分は「…」。ないときは出さない |
| 本文 | 3行まで、はみ出す分は「…」 |
| 次の一歩の件数 | 完了したAI提案の数を、芽のアイコンと「次の一歩 2件」で表示。0件のときは出さない |

- 引用・本文を省略する理由：本文は最大1000字あり、全文を出すと1件で画面が埋まるため。続きは気づきの詳細で読む。
- 次の一歩の件数は、完了したAI提案だけを数える（要件定義書 5.5 のとおり）。

### 表示する項目と出どころ

| 項目 | 出どころ |
| --- | --- |
| 表紙・タイトル・著者 | 本棚にある本はデータベース（本）。削除済みの本は、気づきに記録した本の情報 |
| 本棚から削除済みか | データベース |
| 気づきの件数 | データベース（この本の気づきを数える） |
| ページ・書いた日・引用・本文 | データベース（気づき） |
| 次の一歩の件数 | データベース（その気づきの完了したAI提案を数える） |

### 並び順と読み込み

- 書いた日時が新しい順（固定）。並び替えは作らない。
- 20件ずつ読み込み、下までスクロールしたら次を読み込む。理由：気づきのカードは本より縦に長いため、本棚の30冊より少なくする。

### 操作と移動先

| 操作 | 結果 |
| --- | --- |
| 戻るボタン | 前の画面へ（気づき一覧なら、選んでいた並び順のまま） |
| 気づきを押す | 気づきの詳細へ |
| 「＋気づきを書く」 | 気づきの作成へ（この本を選んだ状態） |

- 気づきの編集・削除は、この画面では行わず、気づきの詳細の「⋮」から行う（アプリ全体で統一）。

### 本棚から削除した本の場合

- 本の情報の下に「本棚から削除済み」と表示する。
- 一覧の上に「この本は本棚から削除されているため、新しい気づきは書けません。」と表示し、「＋気づきを書く」は出さない。理由：気づきは本棚にある本に書く決まりのため（要件定義書 5.3）。
- 今ある気づきは、これまでどおり見る・編集する・削除する・AI提案を受けることができる。
- サーバーでも、削除済みの本への新しい気づきは受け付けない。
- 同じ本を本棚に登録し直しても、気づきは自動で付け直さない（要件定義書 5.4 のとおり。付け直す機能は MVP では作らない）。

### 状態

| 状態 | 表示 |
| --- | --- |
| 読み込み中 | 本の情報と、カードの形のスケルトン |
| 通常 | 上の配置のとおり |
| 気づきがまだない（本棚にある本） | 「まだ気づきがありません」「心に残った一文や、読んで考えたことを書き留めてみましょう。」と、真ん中に「＋気づきを書く」。右下のボタンは出さない（同じボタンを2つ出さないため） |

### API（api.md で詳しく決める）

- 本ごとの気づきの取得：本の情報（削除済みかを含む）と、気づき（ページ・書いた日時・引用・本文・完了したAI提案の数）を20件ずつ、新しい順で返す。自分のものだけを返す。
