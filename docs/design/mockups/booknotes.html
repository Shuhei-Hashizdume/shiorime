本ごとの気づき一覧の画面案

気づき一覧や本の詳細から開く、1冊の本の気づきを並べる画面です。気づきを押すと「気づきの詳細」に移ります。表紙の絵と文章は仮のものです。

1. 通常

上に本の表紙・タイトル・著者・件数。気づきは1件ずつカードで、ページ・書いた日・引用（紙片・2行まで）・本文（3行まで）・次の一歩の件数。書いた日が新しい順に並べる（並び替えはなし）。右下の「＋気づきを書く」から書ける。

2. 通常（朝）

同じ画面の明るい表示。引用は紙片の上に置く。

3. 気づきがまだない

気づき一覧で0件の本を押したときなど。真ん中に「＋気づきを書く」を出し、右下のボタンは出さない。

4. 本棚から削除した本

「本棚から削除済み」と表示し、新しく気づきは書けない（本が本棚にないため）。今ある気づきは見られる。
