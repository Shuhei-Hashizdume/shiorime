次の一歩の作成中・完了・失敗（気づきの詳細）

AI提案画面で回答を送ったあと、画面を離れて気づきの詳細を開いた場面です。気づきのカードより下（次の一歩の欄）だけを見せています。新しいAI提案が完了したときだけ前の次の一歩と置き換わり、完了しなかったら前のものが残ります。文章は仮のものです。

1. 作成中（前の次の一歩あり）

前の次の一歩は消さずに残し、その下に芽が育つ動きと「新しい次の一歩を作成中です…」。完了するまで置き換えない。ボタンは押せない見た目で「AI提案を処理中です」。

2. 作成中（はじめてのAI提案）

前の次の一歩がないときは、作成中の表示だけ。AI提案画面の作成中と同じ芽の動きで、同じ処理が続いているとわかるようにする。

3. 開いている間に完了した

2秒ごとの問い合わせで完了を受け取り、新しい次の一歩に置き換えて、トースト「次の一歩ができました」。

4. 失敗した

前の次の一歩は残し、ボタンの上に失敗したことを知らせる。色だけで伝えず、記号と文を添える。ボタンは押せる状態に戻る。
