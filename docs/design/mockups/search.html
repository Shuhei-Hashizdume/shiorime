本の検索・登録の画面案

本棚の「本を追加」から開く画面です。検索 → 結果から選ぶ → シートで読書ステータスを選んで追加、の流れです。見つからない場合は手入力で追加します。表紙の絵は仮のものです。

1. 開いたとき

検索欄に自動でカーソルが入り、すぐ入力できる。入力するたびには検索せず、キーボードの「検索」か Enter で検索する。

2. 検索中

結果と同じ形のスケルトンを出す。

3. 検索結果

表紙・タイトル・著者・出版年を1行ずつ並べる。本棚にある本には「本棚にあります」と表示し、押すと本の詳細へ。一番下に手入力への案内。

4. 追加の確認（シート）

結果を押すと、下からシートが出る。選んだ本を確かめ、読書ステータスを選んで追加する。初めは「読書中」。

5. 見つからない

検索の言葉を見直す案内と、手入力で追加するボタンを出す。

6. 手入力で追加（シート）

タイトル（必須）と著者（任意）だけ。タイトル欄には検索した言葉を最初から入れておく。表紙はアプリのアイコン画像。
