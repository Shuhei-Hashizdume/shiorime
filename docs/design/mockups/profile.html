プロフィールの画面案

共通メニューの「プロフィール」から開く画面です。設定の項目を、目的ごとのまとまりに分けて並べます。変更・確認はシートで行います。

1. 通常（夜）

アカウント・表示・今日のAI提案・その他、の順。ログアウトと退会は一番下に分けて置く。

1-2. 下までスクロールしたところ

利用規約・プライバシーポリシーはモーダルで開く。ログアウトは確認なし、退会は夕焼けの色で確認のシートへ。

2. 通常（朝）

表示の切り替えで「朝」を選んだところ。選ぶとすぐ画面が切り替わる。

3. 属性の変更（シート）

5つから選ぶ。選ぶとすぐ保存し、シートを閉じてトースト「属性を変更しました」。

4. パスワードの変更（シート）

今のパスワードと新しいパスワード。変更すると、すべての端末でログアウトし、ログイン画面へ（要件のとおり）。

5. 退会（シート）

消えるものを具体的に伝え、パスワードを入れて退会する。退会したらログイン画面へ。
