新規登録・ログインの画面案

ウェルカムページの「はじめる（新規登録）」「ログイン」から開く画面です。この見本から、書体をキウイ丸1つ（ロゴの文字だけ Zen 丸ゴシック）にしています。ブラウザで開くと正しい書体で表示されます。

1. 新規登録

メールアドレス・パスワード・属性・同意の4つ。属性は5つのボタンから選ぶ。登録したら本棚（本がまだない状態）へ。

2. 新規登録のエラー

「はじめる」を押したときに確かめ、直し方をそれぞれの欄の下に出す。

3. ログイン

メールアドレスとパスワード。ログインしたら本棚へ。

4. ログインの失敗

どちらが違うかは伝えない（他人のメールアドレスが登録されているかを知られないため）。回数制限に達したときの文も決める。

5. お知らせ付きのログイン

パスワード変更・退会・ログインの有効期限切れのあとに開いたとき、画面の上にお知らせを出す。
